# Pamięć projektu Dzień Mężczyzny — nowa strona

- To statyczny prototyp odświeżenia dzienmezczyzny.pl; obecny WordPress pozostaje działającym serwisem.
- Repozytorium: https://github.com/PrzemoWAkcji/dzien-mezczyzny-nowa-strona
- Publiczny podgląd GitHub Pages: https://przemowakcji.github.io/dzien-mezczyzny-nowa-strona/
- Treści i zdjęcia próbki są zapisane lokalnie. `python3 scripts/build_content.py` odświeża je z publicznego WordPress API.
- Preferencja wizualna: projekt ma być podobny do oryginalnego serwisu (biało-szara baza, czerwono-pomarańczowe akcenty, duży nagłówek magazynu, zdjęcia z nałożonymi tytułami), ale nie być identyczną kopią.
- Oryginalne logo desktopowe i mobilne są w `assets/original-logo.png` oraz `assets/original-mobile-logo.png`; obecny WordPress używa krojów Open Sans i Lora.
